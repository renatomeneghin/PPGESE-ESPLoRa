# Pacote de upload — ESP-LoRa-TinyML

## Objetivo

Use esta pasta para criar o portfólio do projeto em outra conta Google com o Google Sites habilitado.

## Arquivos a enviar ao Google Drive

1. `01_ESP-LoRa-TinyML-final.zip` — código-fonte e configuração PlatformIO.
2. `02_Video_Demonstracao_01.mp4` — primeira demonstração.
3. `03_Video_Demonstracao_02.mp4` — segunda demonstração.
4. `04_Relatorio_Projeto_Final.pdf` — relatório final.
5. `05_PORTFOLIO.md` — texto-base para a página inicial.

## Organização recomendada

1. Crie uma pasta no Google Drive chamada `ESP-LoRa-TinyML - Portfólio`.
2. Envie os cinco arquivos para essa pasta.
3. Crie um Google Site com o título `ESP-LoRa-TinyML — Portfólio`.
4. Na página inicial, use o conteúdo de `05_PORTFOLIO.md`.
5. Adicione uma seção `Demonstrações` e insira os dois vídeos a partir do Google Drive.
6. Adicione uma seção `Relatório e código` com o PDF e o arquivo ZIP.
7. Publique como `esp-lora-tinyml-portfolio` ou outro endereço disponível.

## Texto sugerido para a página inicial

**ESP-LoRa-TinyML — sistema embarcado com LoRa e TinyML**

Protótipo desenvolvido para a Heltec WiFi LoRa 32 V2. O sistema combina BME280, MPU6050, FreeRTOS, filtragem FIR, classificação Edge Impulse e transmissão LoRa usando RadioLib.

**Fluxo:** aquisição dos sensores → tasks FreeRTOS → magnitude da aceleração → filtro FIR → inferência TinyML → quadro binário com CRC16 → transmissão LoRa.

## Observações

- Os vídeos e o relatório serão armazenados na nova conta Google.
- O arquivo ZIP contém o código e as dependências locais do modelo TinyML.
- Verifique as permissões dos arquivos antes de publicar o site.
- A conta atual da UFSC não permite criar Google Sites porque o serviço está desabilitado pela organização.
